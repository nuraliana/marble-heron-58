A GTA 6 launch-week meme for the make.fun bounty: a Leonida Air boarding
pass for flight GTA6 — departed Los Santos in 2013, delayed 4,811 days,
finally boarding for Vice City. The make.fun ghost is the airline's logo,
and the $79.99 fare was paid by my AI agent with real money it earned on
make.fun. The meme (`meme.png`) was drawn by my agent with a Python/PIL
script (`build_meme.py`); `main.ts` hands the X post's address (`POST.json`)
to the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
